# Карта переводимых строк — BrowserPalette

> Источник: `Sources/AddOnResources/RFIX/HTML/Interface_ru.html`.
> Извлечение: одноразовый скрипт `inventory_extract.js` (не в репозитории).
> Результат на момент старта: **802 строковых литерала, 383 уникальных, из них 192 с кириллицей.**

Это рабочая карта, а не список готовых ключей. Ключи появляются при миграции
(шаги 08–13 плана `.hermes/plans/2026-10-03_115258-interface-english-localization.md`)
и фиксируются в маркированном RU-каталоге внутри HTML.

## Категории

| Категория | Что означает | Перевод |
|---|---|---|
| **UI** | Подписи, заголовки, состояния, сообщения, `aria-label`, `placeholder` | да |
| **PROJECT** | Имена свойств, групп, классификаций, избранного, значения из проекта | **нет** |
| **PROTOCOL** | Значения `option.value`, enum-коды, JSON-ключи, `data-role`, DOM-id | **нет** |
| **DSL** | Текст команд Sync/Spec/Renum/Sum, примеры скриптов, regex | **нет** |
| **DEMO** | Демонстрационные данные мок-моста | частично, только подписи |
| **COMMENT** | Комментарии в коде | **нет** |

## 7. Комментарии и не переводимое (`COMMENT`, `PROTOCOL`)

Комментарии `//` не переводятся (ASCII-требование кода).
Латинские строки `undefined`, `button`, `span`, `div`, `var(--ac-*)`,
`mouseenter`, `click`, `errorPropertyname`, `Light/dark`, SVG-разметка —
PROTOCOL/разметка, не переводятся. Латинские диагностики
(`bridge not ready`, `AGENT TODO`) — технические, остаются как есть.

## Ловушки, требующие решения до перевода

1. **`Закреплённые` (1867, 1877)** — одновременно отображаемая подпись синтетической
   группы и признак её типа в сравнении. Подстановка перевода сломает сравнение.
   Решение: отдельный служебный флаг в JS-модели рендера; состояние
   сворачивания синтетической группы хранить не в map пользовательских имён.
   Проверить случай, когда пользователь назвал свою группу «Закреплённые».

2. **`без суффикса` (2362)** — одновременно `text` и `value` опции. Перевод
   `value` изменит генерируемое правило. Решение: разделить `value` (оставить
   `без суффикса`) и подпись (перевести).

3. **`Без группы` (370, 404)** — проверяется, используется ли как имя группы
   или как текст-подсказка. Читать регион перед переводом.

4. **Фрагменты предложений** (1559–1560, 1572, 2342, 2645, 2647, 2654, 2657,
   2870–2872, 3059) — склейка строк. Решение: целые сообщения с параметрами.

5. **`parseErrorText` (2573)** — приходит из C++ (`BrowserPalette.cpp:229, 234–237`).
   Локализовать по коду `parseError`, а не по тексту; неизвестный код —
   английское общее сообщение + исходная диагностика как техническая подробность.

6. **`SPEC_STATUS_LABEL` / `SPEC_ORIGIN_LABEL`** — enum-ключи PROTOCOL. Локализовать
   значения через отдельную таблицу `spec.status.*` / `spec.origin.*`,
   сами ключи не трогать.

## Что НЕ считается пропуском

Наличие кириллицы в DEMO/DSL/PROTOCOL/COMMENT — не дефект перевода. Полноту
покрытия UI даёт обход по этой карте, а не regex-поиск кириллицы: тот находит
законные нестроковые данные и пропускает латинские UI-строки.
