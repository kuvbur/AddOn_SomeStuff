# Скиллы для работы с SomeStuff через ИИ

В этой папке собраны переносимые материалы для ассистентов, работающих с открытым проектом Archicad и аддоном SomeStuff.

## Создание и обновление отделки

[archicad-zone-finish](archicad-zone-finish/SKILL.md) помогает ассистенту найти помещение по номеру или названию, а затем запустить отделку только для указанной зоны через JSON-команду SomeStuff. Пример запроса ассистенту: «Создай отделку в помещении 123».

**Совместимость:** адресный вызов требует сборку аддона, которая действительно поддерживает параметр `zones`. На момент подготовки комплекта эта возможность присутствует в рабочей версии исходников, но не подтверждена для каждой опубликованной сборки. Старый аддон может проигнорировать параметр и обработать все доступные зоны. Перед запуском ассистент обязан подтвердить именно загруженную сборку; при сомнении он остановится.

### Как передать скилл ассистенту

Скопируйте папку `archicad-zone-finish` целиком в каталог пользовательских скиллов вашего ассистента или передайте ему `SKILL.md` вместе с папками `references` и `scripts`. Способ установки и доступ к локальным инструментам зависят от используемого ассистента — следуйте его документации. Одного текста чата недостаточно, если ассистент не может отправлять запросы в локальный JSON-интерфейс Archicad.

Структура:

- `archicad-zone-finish/SKILL.md` — инструкция для ассистента и защитные проверки.
- `archicad-zone-finish/references/room-finish-json.md` — форматы запросов, проверка результата и ограничения.
- `archicad-zone-finish/references/finish-configuration-json.md` — проверка и согласованное создание избранного и классификаций, проверка свойств.
- `archicad-zone-finish/scripts/find_zones.py` — необязательный инструмент поиска зон без изменения модели; ему нужен Python 3 со стандартной библиотекой. Он не запускает отделку.

Проверка сценария создания проводилась в Archicad 25 Windows на тестовом проекте; для других версий и конкретных сборок требуется отдельная проверка. Комплект не изменяет настройки и не устанавливает аддон автоматически.
