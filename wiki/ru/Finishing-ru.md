## Ведомость отделки

[Тестовый файл](https://github.com/kuvbur/AddOn_SomeStuff/blob/master/wiki/files/%D0%9E%D1%82%D0%B4%D0%B5%D0%BB%D0%BA%D0%B0_25.pla)

Делает разбивку по составу прилегающих конструкций, записывает информацию о слоях прилегающих конструкций.

Аддон работает в **двух параллельных и независимых способах** - их можно использовать как поодиночке, так и вместе:

1. **Запись ведомости отделки в свойства зоны** - аддон рассчитывает площади и материалы отделки (по слоям прилегающих конструкций от зоны наружу) и записывает результат в свойства зоны. Никакие элементы модели при этом не создаются.
2. **Построение отделочных элементов** - аддон строит дополнительные отделочные элементы поверх существующих конструкций (аналогично Мастеру интерьера): стены, колонны, полы, потолки, откосы, плинтусы и карнизы. Запись в свойства зоны при этом не требуется.

Управление способами раздельное: запись результатов включается наличием свойств записи (см. [«Свойства зон для записи результатов»](#свойства-зон-для-записи-результатов)), построение элементов - свойствами создания (см. [«Управление созданием элементов»](#управление-созданием-элементов)).

### Ограничения

- Не учитывает подрезку зоны крышей
- Не работает с твердотельными операциями над зонами/ограничивающими конструкциями
- Для полов вычитается сечение прямых стен со сложным профилем на отметке низа зоны; наклонные/модифицированные профили и mesh-полы не проверены
- Для откосов использует только параметры проёма (`some_stuff_reveal_onoff`, `gs_frame_thk`, `gs_wido_sill`), а не настройки расчёта зон
- Не обрабатывает лестницы

### Свойства строительных материалов

Аддон анализирует слои стен с типом «Отделка», собирая данные от зоны наружу до первого слоя «Ядро» (включительно). **Внимание:** в конструкциях без слоя «Ядро» выводятся ВСЕ слои.

| Свойство                         | Тип                   | Описание                                                                                                                                                                                                                                        |
| -------------------------------- | --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `some_stuff_layer_onoff`         | Критерий соответствия | Вывод слоя в ведомость отделки                                                                                                                                                                                                                  |
| `some_stuff_layer_has_finish`    | Критерий соответствия | Добавление финишного слоя из параметров зоны (опционально). При отключении финишный слой из зоны заменяется материалом, указанным в настройках строительного материала.                                                                         |
| `some_stuff_layer_description`   | Текст                 | Название материала. Описание свойства подставляется в выражение свойств Archicad, поэтому поддерживаются выражения вида `%СвойстваСтроительногоМатериала/Имя%`; по умолчанию используется `%BuildingMaterialProperties/Building Material Name%` |
| `some_stuff_layer_favorite_name` | Текст                 | Имя избранного (опционально)                                                                                                                                                                                                                    |

При отсутствии свойств выводятся наименования всех отделочных слоёв.

### Свойства зоны

Создаваемые отделочные стены будут разбиты по высоте согласно настроек свойств зоны. Всего возможно три участка по высоте зоны:

- **низ стен/колонн (панели)** - от низа зоны вверх на высоту панелей;
- **основная часть отделки** - от панелей до отметки потолка;
- **верхняя полоса** - от подвесного потолка до верха стены (пространство между подвесным потолком и перекрытием).

Высоты участков задаются свойствами (описания) `some_stuff_fin_down_height` и `some_stuff_fin_main_height`; верхняя полоса занимает остаток высоты. Если какой-то участок не задан - он пропускается.

#### Свойства зон для чтения

| `some_stuff_fin_ceil_by_slab`  | Считать и строить потолок (и карниз потолка) только по перекрытиям | Критерий соответствия |

В случае использования других зон необходимо создать свойства со следующим описанием (т.е. создать свойство и добавить в его описание нужный текст):

| `some_stuff_fin_down_height`     | Высота панелей                                                                                | Длина      |

#### Свойства зон для записи результатов

Обязательные для записи свойства перечислены ниже. Их имена также не фиксированы: в колонке «Описание для свойства» указан текст, который нужно добавить в описание свойства зоны, а имя свойства может быть любым - аддон находит свойства по их описанию.

Используются для выводов результата без построения отделочных элементов. Все слои отделки записываются в одну ячейку.
Тип свойства для записи результатов - строка. Запись не производится, если для какой-либо из обязательных ролей (стены, низ, колонны, потолок) не найдено ни собственного свойства, ни его пары `_bytype`. Для низа и колонн достаточно наличия пары `some_stuff_fin_main_result` / `some_stuff_fin_main_result_bytype` - она используется как fallback. При отсутствии обязательного свойства расчёт записи прерывается (перечень имён - в сообщении, см. [раздел «Возможные проблемы»](#возможные-проблемы)). Для верха и откосов при отсутствии собственного свойства используется соответствующее свойство основной части. Расчёт площади выполняется без учёта пересечений/вычитаний отделочных стен.

| Описание для свойства          | Назначение                                               | Примечание                                                                                                    |
| ------------------------------ | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `some_stuff_fin_ceil_result`   | Отделка потолка                                          | Обязательное (или `_bytype`)                                                                                  |
| `some_stuff_fin_main_result`   | Отделка стен                                             | Обязательное (или `_bytype`)                                                                                  |
| `some_stuff_fin_up_result`     | Отделка верха стен, от подвесного потолка до верха стены | Если не задано - используется `some_stuff_fin_main_result`                                                    |
| `some_stuff_fin_down_result`   | Отделка низа стен/колонн                                 | Если не задано - используется `some_stuff_fin_main_result`, поэтому пара `main` покрывает требование          |
| `some_stuff_fin_column_result` | Отделка колонн                                           | Если не задано - используется `some_stuff_fin_main_result`, поэтому пара `main` покрывает требование          |
| `some_stuff_fin_reveal_result` | Отделка откосов                                          | Если не задано - используется `some_stuff_fin_main_result`. Также принимается `some_stuff_fin_reveals_result` |

Запись результатов с группировкой по типам отделки:

| Описание для свойства                 | Назначение               | Примечание                                                                                                                  |
| ------------------------------------- | ------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| `some_stuff_fin_ceil_result_bytype`   | Отделка потолка          | Обязательное (или `some_stuff_fin_ceil_result`)                                                                             |
| `some_stuff_fin_main_result_bytype`   | Отделка стен             | Обязательное (или `some_stuff_fin_main_result`)                                                                             |
| `some_stuff_fin_up_result_bytype`     | Отделка верха стен       | Если не задано - используется `some_stuff_fin_main_result_bytype`                                                           |
| `some_stuff_fin_down_result_bytype`   | Отделка низа стен/колонн | Если не задано - используется `some_stuff_fin_main_result_bytype`                                                           |
| `some_stuff_fin_column_result_bytype` | Отделка колонн           | Если не задано - используется `some_stuff_fin_main_result_bytype`                                                           |
| `some_stuff_fin_reveal_result_bytype` | Отделка откосов          | Если не задано - используется `some_stuff_fin_main_result_bytype`. Также принимается `some_stuff_fin_reveals_result_bytype` |

#### Форматирование вывода (шрифт, размер шрифта)

Поскольку все материалы вместе с площадью записываются в одну ячейку, аддон подбирает переносы на основании данных о шрифте и размере предполагаемых столбцов. По умолчанию аддон настроен на работу со шрифтом GOST 2.304 type A, размер шрифта 2.5, ширина для материала 40мм, для площади 20мм (общая ширина столбца в ИК - 60мм).

Для задания иных значений в описание нужного столбца вывода результата добавить в формате `{ШИРИНА_НАЗВАНИЯ ; ШИРИНА_ПЛОЩАДИ ; РАЗМЕР ; ШРИФТ ; ПРОБЕЛ ; УЗКИЙ_ПРОБЕЛ}`, например `{ 50 ; 30 ; 3 ; ISOCPEUR }`.

- Параметры 5 и 6 необязательны и задают символы пробела для переносов: `nbs` - неразрывный пробел (U+2007), `ns` - узкий неразрывный пробел (U+202F), `s` - обычный пробел.
- Если фигурные скобки в описании есть, но ширина/размер не указаны, принимаются значения 50 / 20 / 2.5, а шрифт по умолчанию меняется на `Arial` (если заданный шрифт не найден - также `Arial`).

## Настройки создаваемых отделочных элементов

Данные настройки требуются только для создания отделочных элементов и не влияют на запись ведомости отделки в зону.

Если в проекте есть комбинация слоёв, имя которой оканчивается на `smstf_fin`, аддон применяет её перед созданием элементов.

### Классификация отделочных элементов

Для работы необходимо настроить классы отделочных элементов. Настройка заключается в добавлении в Описание класса следующего текста:

- `some_stuff_fin_class` - Общий класс для всех элементов. Назначается, если не найдены остальные классы.
- `some_stuff_fin_walls` - Для стен (если не задан - примет класс `some_stuff_fin_class`)
- `some_stuff_fin_down_walls` - Для низа стен (если не задан - примет класс `some_stuff_fin_walls` или `some_stuff_fin_class`)
- `some_stuff_fin_reveals` - Для откосов (если не задан - примет класс `some_stuff_fin_walls` или `some_stuff_fin_class`)
- `some_stuff_fin_windows_reveals` - Для откосов окон (необязательный, распознаётся как `some_stuff_fin_reveals`)
- `some_stuff_fin_doors_reveals` - Для откосов дверей (необязательный, распознаётся как `some_stuff_fin_reveals`)
- `some_stuff_fin_columns` - Для колонн (если не задан - примет класс `some_stuff_fin_class`)
- `some_stuff_fin_floors` - Для полов (если не задан - примет класс `some_stuff_fin_class`)
- `some_stuff_fin_ceils` - Для потолков (если не задан - примет класс `some_stuff_fin_class`)
- `some_stuff_fin_skirting` - Для плинтуса пола (отдельный класс, без fallback)
- `some_stuff_fin_cornice` - Для карниза потолка (отдельный класс, без fallback)

Для корректной работы аддона достаточно существования класса с описанием `some_stuff_fin_class`, кроме плинтусов и карнизов - для них нужны отдельные классы. Остальные классы можно создавать при необходимости. Классификацию элементам задаёт сам аддон в процессе создания отделочных элементов, назначать их элементам вручную не требуется. Элементы, классифицированные как отделочные, не учитываются при расчётах.

Классы `some_stuff_fin_ceil_beams` и `some_stuff_fin_wall_beams` объявлены в коде, но в текущей логике не используются.

### Свойства отделочных элементов

Свойства должны быть видны в классификации отделочных элементов.

В таблице указан текст для **описания** свойства, а не его имя. Имя свойства может быть любым — аддон находит его по описанию.

| Свойство                 | Тип данных                 | Описание                                                                             |
| ------------------------ | -------------------------- | ------------------------------------------------------------------------------------ |
| `Sync_GUID base element` | Строка, одиночное значение | Для записи аддоном GUID базового элемента, с которым будет связан отделочный элемент |
| `Sync_GUID zone`         | Строка, одиночное значение | Для записи аддоном GUID зоны                                                         |
| `some_stuff_element_tip_skirting` | Строка, одиночное значение | Тип плинтуса пола или карниза потолка, записываемый в соответствующее отделочное перекрытие |
| `some_stuff_element_length_skirting` | Длина, одиночное значение | Суммарная расчётная длина плинтуса пола или карниза потолка для соответствующего отделочного перекрытия |

Свойства для записи типа и длины плинтуса необязательны и используются независимо друг от друга. Они должны быть доступны в классификации отделочных полов и потолков. При повторном расчёте значения обновляются; если плинтуса или карниза больше нет, записывается нулевая длина, а тип очищается.

Для общих ролей обязательным является `Sync_GUID zone` - без него расчёт останавливается с ошибкой конфигурации. Отсутствие `Sync_GUID base element` в общих ролях лишь выдаёт предупреждение: обновление существующих элементов пола/потолка будет выполнено заменой.

Для плинтусов и карнизов проверка свойств связи строгая: `Sync_GUID zone` и `Sync_GUID base element` должны иметь тип `Строка`, коллекцию `Одиночное значение` и быть явно доступны в классе соответствующей роли, иначе расчёт завершается ошибкой конфигурации.

### Плинтусы и карнизы

Плинтус пола и карниз потолка - отдельные роли (`Floor_Skirting`, `Ceil_Cornice`), которые создаются только из элементов типа «Балка».

- Для них используются отдельные классы `some_stuff_fin_skirting` и `some_stuff_fin_cornice`; fallback на `some_stuff_fin_class` не применяется.
- Если класс роли отсутствует или не распознан, расчёт завершается ошибкой конфигурации.
- Свойства `Sync_GUID zone` и `Sync_GUID base element` обязательны и должны быть строкой с одиночным значением, доступной в классе роли.

Как создаются: плинтус пола строится вдоль низа отделочных стен и колонн (роли `Wall_Main`, `Wall_Down`, `Wall_Up`, `Column`), карниз потолка - вдоль их верха; элемент строится **только типом «Балка»**. Форма плинтуса повторяет сегменты основания, включая обход проёмов.

Тип плинтуса пола и тип карниза потолка задаются параметрами зоны библиотеки отделки: `tip_plint_pol` и `tip_plint_pot`. Значение параметра, содержащее «не задан», отключает построение соответствующей роли; значение «по типу» подставляет тип отделки пола/потолка этой зоны; пустой тип также отключает построение.

Подбор избранного учитывает тип плинтуса так же, как для полов и потолков. Если тип плинтуса задан, сначала среди всех записей избранного ищется запись, имя которой содержит `_<тип плинтуса>_` и суффикс `_smstf` (например, при типе «дюралайт» - `Плинтус_дюралайт_smstf`); берётся первая запись, у которой тип инструмента - **балка** или **объект (аксессуар)**; имена сравниваются без учёта регистра. Состав выбранного tip-избранного читается вместе с записью и используется при подборе.

Если подходящей tip-записи нет (или тип плинтуса не задан), применяется имя по умолчанию `smstf skirting` / `smstf cornice`; если в избранном нет элемента с таким именем, настройки инструмента для плинтуса/карниза не применяются (fallback на `smstf wall` или настройки инструмента по умолчанию не действует).

### Наклонные полы (3D-сетки)

Если основой пола является 3D-сетка (Mesh), отделка пола строится не перекрытием, а элементом **«Крыша»** (плоская крыша) с контуром сетки; параметры при этом читаются из избранного типа «Перекрытие» (`smstf floor` или указанное в имени покрытия). Площадь отделки в ведомости считается по фактической наклонной поверхности (а не по проекции). Толщина отделки задаётся по нормали к поверхности; плинтус вдоль наклонного пола учитывает эту толщину при построении.

### Свойства базовых элементов

- `some_stuff_element_has_finish` - вместо финишной отделки зоны к элементу будет применен материал (покрытие) последнего слоя.
- `some_stuff_element_onoff` - полное отключение обработки элемента ведомостью отделки.
- `some_stuff_reveal_onoff` - для окон и дверей (критерий соответствия). Откосы создаются для **всех проёмов**, у которых значение этого свойства **не равно «Ложь»**; если у проёма такого свойства нет (или оно не валидно) - откосы также создаются. Отключить откосы можно только явно задав значение «Ложь».

### Создание элементов отделки из Избранного

Аддон проверяет - есть ли в имени финишного покрытия в зоне указание на имя избранного. Имя покрытия при этом формируется в формате `ИМЯ_ПОКРЫТИЯ@ИМЯ_ИЗБРАННОГО`, например `Окраска краской@Стена` - где `Окраска краской` - имя покрытия в ведомость отделки, а `Стена` - имя элемента в избранном.

Если для покрытия не указано избранное (т.е. в имени покрытия нет символа `@` или избранное с таким именем не найдено), будет произведён поиск элементов избранного по типу отделываемой поверхности:

- `smstf window` - проём для вставки в отделочные стены в местах окон, дверей. Тип инструмента - окно
- `smstf wall` - отделка вертикальных поверхностей. Тип инструмента - стена или объект (аксессуар)
- `smstf ceil` - для моделирования потолков. Тип инструмента - перекрытие или объект (аксессуар)
- `smstf floor` - для моделирования полов. Тип инструмента - перекрытие или объект (аксессуар)
- `smstf reveal side` - для моделирования вертикальной части откосов. Тип инструмента - стена или объект (аксессуар)
- `smstf reveal up` - для моделирования горизонтальной части откосов. Тип инструмента - балка
- `smstf ceil side` - для стен на перепадах потолка. Тип инструмента - стена или объект (аксессуар)
- ~~`smstf floor side`~~ - имя сохранено для совместимости чтения, но больше не выбирается: стены на перепадах пола используют `smstf wall` (тип инструмента - стена или объект (аксессуар))
- `smstf skirting` - для плинтуса пола. Тип инструмента - только балка; fallback на `smstf wall` или материал не применяется
- `smstf cornice` - для карниза потолка. Тип инструмента - только балка; fallback на `smstf wall` или материал не применяется

Для полов и потолков, если в имени покрытия есть указание на избранное (`ИМЯ@ИЗБРАННОЕ`), оно используется в первую очередь.
Если указания нет (или избранное с таким именем не найдено), выполняется поиск по **типу из зоны** (свойства зоны `some_stuff_fin_type_ceil` / `some_stuff_fin_type_floor` - «Тип отделки потолка / пола для объединения зон»):

- среди всех записей избранного, имя которых содержит `_<тип_отделки>_` и суффикс `_smstf` (например, при типе отделки «армустронг» - `Потолок_армустронг_smstf`), берётся первая, у которой тип инструмента - **перекрытие** или **объект (аксессуар)**; имена сравниваются без учёта регистра.
- если и такой записи нет - применяются имена по умолчанию `smstf floor` / `smstf ceil` (с тем же приёмом типа);
- если и там ничего подходящего не нашлось - применяются настройки инструмента по умолчанию (для полов и потолков этот fallback действует).

Если ни на одном шаге подходящих элементов не нашлось - будут применены настройки инструмента по умолчанию (стены и перекрытия). Для плинтусов и карнизов этот fallback не действует.

## Возможные проблемы

| Сообщение | Причина | Следствие |
| --- | --- | --- |
| «Properties for recording finish layers to the Zone were not found. Recording will not be performed. Missing …» | Не найдены обязательные свойства записи результатов (стены, низ, колонны, потолок, или их пары `_bytype`). В перечне `Missing …` указаны недостающие имена. | Запись в свойства зоны не выполняется. |
| «Duplicate properties for materials/elements were found: …» | Найдено несколько свойств с одинаковым описанием (`some_stuff_layer_*`, `some_stuff_element_*`). | Используется первое найденное, остальные перечислены в сообщении. |
| «Required properties 'some_stuff_layer_onoff' and 'some_stuff_layer_description' not found in Building Materials. Processing all Finish layers with Building Material Name as identifier» | В строительных материалах нет свойств отбора слоёв. | Выводятся все отделочные слои, имя материала берётся из имени строительного материала. |
| «'Sync_GUID base element' property found, but not displayed in Finish Element classification. Floor/ceiling updates require this property to be visible. Existing elements will be replaced.» | Свойство `Sync_GUID base element` есть, но не видно в классификации отделочных элементов. | Обновление существующих полов/потолков выполняется заменой элементов. |
| «Missing 'Sync_GUID base element' property. Floor/ceiling updates require this property. Existing elements will be replaced» | Свойство `Sync_GUID base element` не найдено вовсе. | Обновление существующих полов/потолков выполняется заменой элементов. |
| «Recommended items not found in favorites» | В избранном совсем нет элементов `smstf …`. | Все элементы отделки создаются с настройками инструмента по умолчанию. |
| «The recommended elements were not found in Favorites. Default tool settings will be used to create these elements. Missing element names: …» | Части рекомендуемого избранного (`smstf …`) отсутствуют. | Для недостающих применены настройки инструмента по умолчанию; имена перечислены в сообщении. |
| «The recommended elements for reveal were not found in Favorites. 'smstf wall' will be used to create these elements. Missing element names: …» | Для откосов нет `smstf reveal side` / `smstf reveal up`. | Откосы строятся из избранного `smstf wall`; недостающие имена перечислены в сообщении. |

## JSON-команда запуска ведомости отделки

Команда вызывается через HTTP-порт запущенного Archicad (`POST http://127.0.0.1:19723`) и не принимает параметров расчёта: `addOnCommandParameters` можно не передавать или передать пустым объектом.

### Запрос

```json
{
  "command": "API.ExecuteAddOnCommand",
  "parameters": {
    "addOnCommandId": {
      "commandNamespace": "SomeStuffCommand",
      "commandName": "RoomBook"
    },
    "addOnCommandParameters": {}
  }
}
```

### Ответ

Ответ Archicad оборачивает результат команды в `result.addOnCommandResponse`:

```json
{
  "succeeded": true,
  "result": {
    "addOnCommandResponse": {
      "status": "returned",
      "rooms": [
        {
          "zone_guid": "B69820A5-9B3A-4D30-A33A-DE995E4447CB",
          "types": [
            {
              "TypeOtd": 4,
              "elements": [
                {
                  "otd_guid": "93A36784-485B-4D8C-AB6B-F11BB4E94A7A",
                  "base_guid": "61AEC870-2A86-42BB-82E6-8A3FF809CA2F",
                  "write_succeeded": true,
                  "was_created": true,
                  "length": 0.02,
                  "length_available": true,
                  "area": 0.042,
                  "area_available": true,
                  "material": 366,
                  "bmaterial": 3,
                  "structtype": 0
                }
              ]
            }
          ]
        }
      ]
    }
  }
}
```

Поля ответа:

| Поле                          | Тип    | Описание                                                                   |
| ----------------------------- | ------ | -------------------------------------------------------------------------- |
| `status`                      | строка | Признак завершения вызова; текущая реализация всегда возвращает `returned` |
| `rooms`                       | массив | Обработанные помещения (зоны)                                              |
| `rooms[].zone_guid`           | строка | GUID помещения                                                             |
| `rooms[].types`               | массив | Созданные элементы отделки, сгруппированные по типу                        |
| `types[].TypeOtd`             | число  | Числовой тип отделки (`TypeOtd`), см. таблицу ниже                         |
| `types[].elements`            | массив | Элементы отделки данного типа в помещении                                  |
| `elements[].otd_guid`         | строка | GUID созданного или обновлённого элемента отделки                          |
| `elements[].base_guid`        | строка | GUID базового элемента, к которому относится отделка                       |
| `elements[].write_succeeded`  | bool   | Запись элемента в модель завершилась успешно                               |
| `elements[].was_created`      | bool   | Элемент создан в этом запуске (`false` — обновлён существующий)            |
| `elements[].length`           | число  | Погонная длина элемента (для ролей, где она вычисляется)                   |
| `elements[].length_available` | bool   | Признак, что `length` рассчитана                                           |
| `elements[].area`             | число  | Площадь элемента                                                           |
| `elements[].area_available`   | bool   | Признак, что `area` рассчитана                                             |
| `elements[].material`         | число  | Индекс материала отделки                                                   |
| `elements[].bmaterial`        | число  | Индекс строительного материала                                             |
| `elements[].structtype`       | число  | Тип конструкции                                                            |

Значения `TypeOtd`:

| Значение | Тип отделки                               |
| -------- | ----------------------------------------- |
| 0        | Не определено (`NoSet`)                   |
| 1        | Основная часть отделки зоны (`Wall_Main`) |
| 2        | Верхняя часть отделки зоны (`Wall_Up`)    |
| 3        | Нижняя часть отделки зоны (`Wall_Down`)   |
| 4        | Боковая часть откосов (`Reveal_Main`)     |
| 5        | Верхняя часть откосов (`Reveal_Up`)       |
| 6        | Нижняя часть откосов (`Reveal_Down`)      |
| 7        | Отделка колонн (`Column`)                 |
| 8        | Отделка пола (`Floor`)                    |
| 9        | Отделка потолка (`Ceil`)                  |
| 10       | Плинтус пола (`Floor_Skirting`)           |
| 11       | Карниз потолка (`Ceil_Cornice`)           |
| 12       | Отделка балок в потолке (`Beam_Ceil`)     |
| 13       | Отделка балок в стенах (`Beam_Wall`)      |

Ответ не означает, что все перечисленные элементы остались в модели: пакет записи может быть откатан, поэтому ориентироваться нужно на `write_succeeded` и `was_created`.
